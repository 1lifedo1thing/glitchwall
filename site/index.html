A hundred things a minute, in a terminal you're not watching.

glitchwall puts them on your desktop: every shell command, file read and edit, search, web fetch and sub-agent gets a card the moment it runs, types itself out with its result, lingers, and leaves. A failing command shows in the theme's error color. There's nothing to set up in the agent: glitchwall reads the logs it already writes.

Private

Secrets are masked before anything is stored. Logs are opened read-only, and the feed talks to 127.0.0.1 only. No telemetry, no update checks, nothing loaded from the internet.

Light

About 6.5% of one CPU core and 153 MB, drawn by a small Rust renderer with no browser. Screens covered by a window or a game draw nothing.

Stream-safe

Press P and every card is gone at once, enforced by the feed itself. Nothing from a pause is ever replayed.

Nineteen complete looks

Each theme is colors, two fonts, a background, a texture, and its own way of bringing cards in and taking them away. Mix any part of one with another. No videos, no GIFs: every background is a small program drawing each frame live, so no two minutes look the same. Pick one to see it running above.

Settings that show what they pick

  • A theme drum that previews every theme in its own colors and fonts.
  • Knobs: colors as a swatch, a font in its own face, a background as a still, an arrival by playing it.
  • Hold any control and the window fades almost away, so the wallpaper itself is the preview.
  • Everything applies within a second. Nothing restarts.
  • Keyboard all the way, and dockable to a screen edge.

Easy to trust, easy to check

A wallpaper that shows what your agent does has to be careful with it. Here's the whole path a tool call takes, and nothing else leaves it.

Agent logsThe session logs your coding agent already writes on your PC.
Read-onlyOpened read-only; only what's new is read. Nothing is written there.
Masked50+ key formats, secret-named values, passwords in URLs, your home folder and name.
127.0.0.1A local feed with a per-install random key. Other sites and servers are refused.
Your wallpaperDrawn behind your icons. Your own wallpaper file is never changed.
  • It doesn't watch you: not your terminal, your typing, or other windows. It only notes where windows are (to stop drawing under them) and where the mouse is (for the hot corner).
  • A feature that showed your own terminal commands was built, then removed on purpose, because a wallpaper shouldn't look like spyware.
  • Redaction is a safety net, not a guarantee. When you stream or share your screen, press P.

Install

Windows 10 (1803 or newer) or 11. Get uv if you don't have it, then:

> uv tool install glitchwall
> glitchwall install

A 2.9 MB download, about 78 MB installed including the Python uv sets up. install checks for .NET Framework 4.7.2 and WebView2 first (Windows 11 has both) and stops if one is missing; glitchwall never downloads or installs anything itself. glitchwall uninstall removes all of it.

Just want to look first, on your own PC?

> uvx glitchwall demo --open

Made-up calls in your browser, nothing installed, no logs read. Also on PyPI, and every GitHub release carries the same wheel with its SHA-256.

Questions

Will it slow my PC down?

About 6.5% of one core (0.4% of a 16-core CPU) and 153 MB, about the CPU of a simple web wallpaper with less memory. Covered screens, fullscreen games and a locked PC draw nothing. The numbers →

Can I put it on stream?

Yes. glitchwall export DIR writes the page for an OBS browser source or Wallpaper Engine, and glitchwall pause still clears it at once.

macOS or Linux?

Not today. The renderer draws with Direct2D and sits behind the icons through the Windows desktop.

Does this page track me?

No. It's plain files on GitHub Pages: no analytics, no cookies, no fonts or scripts from anywhere else. The wallpaper running at the top plays a made-up session built into the page and makes no requests at all. GitHub itself keeps server logs, as it does for any Pages site.

Can I make a theme?

Themes live in one file, looks.js. A new background is a canvas scene plus a Rust port; see CONTRIBUTING.md.
